# Graphr 0.8.0 Ripwire Lessons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Graphr 0.8.0 with canonical language-family reporting, honest recoverable `search` and `view` pagination, a frozen retrieval gate, and conservative Go graph support.

**Architecture:** Keep the existing seven-tool MCP stdio binary and immutable SQLite snapshots. Query continuations recompute the bounded selected search set or materialized view, verify a snapshot/parameter/content-bound BLAKE3 cursor, and page logical records without persisted cursor state. Go follows the existing parser-to-`Graph` path, with root `go.mod` context captured from the same target and all uncertain resolution represented as gaps; ranking SQL remains test-only unless the frozen relevance, latency, and query-plan gates select it.

**Tech Stack:** Rust 2024, `rmcp`, `serde`/`schemars`, SQLite FTS5 through existing `rusqlite`, BLAKE3, existing Tree-sitter parsers, and `tree-sitter-go = "0.25.0"` as the only new dependency.

**Spec:** `docs/superpowers/specs/2026-09-08-ripwire-lessons-0.8.0-design.md`

## Global Constraints

- Continue to build one Rust binary for Codex and Claude over MCP stdio and keep exactly seven MCP tools.
- Support Rust, Python, JavaScript/JSX, TypeScript/TSX, C++, and Go; add only `tree-sitter-go = "0.25.0"`.
- Add no Java, HTTP, UI, editor integration, embeddings, plugins, migrations, compatibility readers, process execution, or copied Ripwire source.
- Add no Go workspace/nested-module resolution, `replace`, vendor selection, build-tag evaluation, cgo analysis, generated-code detection, type checking, package node, or Go `IMPORTS` edge.
- Add no co-change scoring, PageRank, custom ranker, rank fusion, stemming layer, query router, runtime benchmark mode, new FTS index, or neighbor ranking.
- Keep repository-controlled output deterministic, compact, line-safe, and bound to one immutable snapshot.
- Keep `search.limit` at 1 through 20 as a selected-result ceiling; a cursor never selects rows beyond that ceiling.
- Keep `search` at 1536 bytes and `view` at 4096 bytes; keep `view.depth` at 0 through 6 and `view.max_nodes` at 1 through 50.
- Keep node references, kinds, and source lines whole; shorten only display name/path fields and mark `display_truncated=true`.
- Preserve canonical-root checks, no-follow reads, regular-file and size checks, cancellation, SQLite rollback, and explicit gaps; ambiguity always produces no edge.
- Search and view cursor tokens are at most 160 bytes, use distinct `s1` and `v1` prefixes, and have no compatibility fallback.
- Raise `REVIEW_FORMAT_VERSION` from 6 to 7 with the language assurance fix and `CACHE_FORMAT_VERSION` from 10 to 11 with Go; keep `SCHEMA_VERSION = 8` and cache namespace `graphr/v6`.
- Keep production search row ordering unless one of the two approved SQL candidates passes every frozen relevance, performance, and query-plan gate.
- Required release checks are `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, `cargo build --locked --release`, and `cargo package --locked`.

- [ ] **Step 3: Add the small length-prefixed cursor primitive**

Keep this private to `store.rs`; it is a helper for two query tools, not a public pagination abstraction.

```rust
const CURSOR_HASH_CHARS: usize = 32;

struct ParsedPageCursor {
    offset: usize,
    checksum: String,
}

fn hash_fields(domain: &str, fields: &[&[u8]]) -> String {
    let mut hash = blake3::Hasher::new();
    for value in std::iter::once(domain.as_bytes()).chain(fields.iter().copied()) {
        hash.update(&(value.len() as u64).to_le_bytes());
        hash.update(value);
    }
    hash.finalize().to_hex().to_string()
}

fn parameter_hash(domain: &str, fields: &[&[u8]]) -> String {
    hash_fields(domain, fields)[..CURSOR_HASH_CHARS].to_owned()
}

fn page_cursor_checksum(
    prefix: &str,
    offset: usize,
    snapshot_id: &str,
    parameters: &str,
    materialized: &str,
) -> String {
    let offset = offset.to_string();
    hash_fields(
        "graphr query cursor v1",
        &[
            prefix.as_bytes(),
            offset.as_bytes(),
            snapshot_id.as_bytes(),
            parameters.as_bytes(),
            materialized.as_bytes(),
        ],
    )
}

fn page_cursor_token(
    prefix: &str,
    offset: usize,
    snapshot_id: &str,
    parameters: &str,
    materialized: &str,
) -> String {
    let snapshot = parameter_hash("graphr cursor snapshot v1", &[snapshot_id.as_bytes()]);
    let checksum = page_cursor_checksum(
        prefix,
        offset,
        snapshot_id,
        parameters,
        materialized,
    );
    let token = format!("{prefix}:{offset}:{snapshot}:{parameters}:{checksum}");
    debug_assert!(token.len() <= 160);
    token
}
```

```rust
fn escaped_prefix(value: &str, budget: usize) -> String {
    let mut output = String::new();
    for character in value.chars() {
        let escaped = if character.is_control() {
            character.escape_default().to_string()
        } else {
            character.to_string()
        };
        if output.len() + escaped.len() > budget {
            break;
        }
        output.push_str(&escaped);
    }
    output
}
```

```rust
fn fixture_repository(root: PathBuf) -> Repository {
    Repository {
        root,
        git_dir: PathBuf::new(),
        common_git_dir: PathBuf::new(),
        common_git_dir_dev: 0,
        common_git_dir_ino: 0,
        index_path: PathBuf::new(),
        branch: None,
        head_oid: String::new(),

fn fixture_sources(
    root: &Path,
    sources: &[(&str, Language)],
) -> Result<Vec<CapturedSource>, String> {
    sources
        .iter()
        .map(|(path, language)| {
            let absolute = root.join(*path);
            let metadata = fs::symlink_metadata(&absolute)
                .map_err(|error| format!("cannot inspect {path}: {error}"))?;
            if metadata.file_type().is_symlink()
                || !metadata.is_file()
                || metadata.len() > 2 * 1024 * 1024
            {
                return Err(format!("invalid evaluator source {path}"));
            }
            let bytes = fs::read(&absolute)
                .map_err(|error| format!("cannot read {path}: {error}"))?;
            std::str::from_utf8(&bytes)
                .map_err(|_| format!("evaluator source is not UTF-8: {path}"))?;
            let digest = *blake3::hash(&bytes).as_bytes();
            Ok(CapturedSource {
                path: (*path).into(),
                language: *language,
                git_oid: None,
                content_key: blake3::Hash::from_bytes(digest).to_hex().to_string(),
                parse_context: String::new(),
                content: SourceContent::Captured {
                    relative_path: PathBuf::from(*path),
                    digest,
                },
            })
        })
        .collect()
}
```

`fixture_sources` reads only that constant list, requires each entry to be a regular non-symlink file no larger than 2 MiB, validates UTF-8, hashes its bytes, and preserves list order. This avoids a directory walker and makes adding/removing a corpus source an explicit reviewed line change.
